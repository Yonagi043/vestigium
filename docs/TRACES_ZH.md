# 轨迹：一份文档是怎么读的

[English](TRACES.md) · [阅读语言](LANGUAGE_ZH.md) · [规则](RULES_ZH.md) · [README](../README_ZH.md)

Vestigium（迹）会在你的机器上记下每一次工具调用。这样，“上次那份报告是怎么读的”“在哪里停的”“哪些信号没去跟”这类问题，AI 助手可以查记录来回答，不用自己猜。

## 怎么打开

- **记录**默认是开的。设 `TGLW_TRACE=0` 可以关掉，关掉后什么都不记、也不写盘。
- **`trace` 工具**让 AI 助手能查看记录，这一版默认是关的。接入服务时打开：

```bash
claude mcp add --env TGLW_TRACE_TOOL=1 --transport stdio vestigium -- vestigium mcp
```

不打开这个工具时，原来的 6 个工具和没有它时一模一样。

## 问一次阅读的经过

用自己的话问 AI 助手，比如：*“上次那份 GAO 报告你是怎么读的？哪些信号你没理会？”* 助手会调用 `trace`：

| 参数 | 默认 | 意思 |
|---|---|---|
| `last` | 1 | 看最近几次阅读，最新的在前。一次阅读就是和服务的一段对话 |
| `ignored` | false | 只看每次阅读的结尾，以及后面没有一步去跟的信号 |
| `doc` | 全部 | 只看这份文档的阅读 |
| `help` | false | 改为返回阅读语言的完整说明（见[阅读语言](LANGUAGE_ZH.md#完整说明)） |

一个真实的例子：在样例文档上调了两次工具，先搜索，再读第一条命中。

```text
reading 1 · doc gao-26-107790 · 2 steps
1   find "FEMA staffing gap May 2023" -> hits 5 on p6 p9 p2 · 418t
2   read t111 <- hit 1#1 -> p5-7; figure fig8; tool +p6-7 (grow) 567t; tool +p5 (adjacent) 681t; tool fig-hints 11t · 1427t
stop after 2 · read p5-7 · sections s6 s5 · 1845 tokens
```

怎么读：

- **第 1 步**按意思搜索，得到 5 条命中，排在最前的几条在第 6、9、2 页。命中只是指路，这几页并没有读。这次返回花了 418 token。
- **第 2 步**读了块 `t111`。它的地址来自第 1 步的第 1 条命中（`<- hit 1#1`）。显示了第 5 到 7 页，提到了图 `fig8`。
- **`tool …`** 标出 Vestigium 没被要求、自己做的事，以及各花了多少：补上第 6–7 页的其余内容（`grow`）；因为第 5 页在搜索里排得靠前，把这相邻的一页也带上（`adjacent`）；在图后面加了一句提示。以后有了规则，规则做的事也这样写成 `rule r-… `。
- **最后一行**写明在哪里停的、真正读了哪些页（这些页的文字或图片返回了）、它们属于哪些节，以及工具一共返回了多少 token。
- 加上 `ignored=true`，还会列出后面没有一步去跟的信号，比如 `ignored: continues p151 (3)`：第 3 步说这一节接到第 151 页还没完，之后没有去读它。

## 轨迹看不到的东西

服务端只看得到工具调用。它看不到模型的思考、模型记下的要点，也看不到最后的答案，所以轨迹的结尾是“stop after N”（最后一次调用之后停了），而不是答案。轨迹只记事实，不记意图：它不会说某次搜索是在换说法，还是在核对。

## 存了什么，存在哪里

- **只存在你的机器上。** 轨迹是 `$VESTIGIUM_HOME/traces` 下的文件（默认 `~/.vestigium/traces`），每个服务进程一个文件。不上传任何东西，断网也能用。
- **谁能读。** 文件只有你自己能读；目录如果是 Vestigium 新建的，也只对你开放。
- **里面有什么。** 调用的工具和参数（文档名、地址、AI 助手的搜索词）、显示了哪些页和节、命中的地址、计数、token 数、信号，以及工具自己加了什么。
- **不存文档原文。** 段落、摘录、命中的句子都不存。
- **搜索词。** 这是 AI 助手写的话，但可能抄了文档里的短语。设 `TGLW_TRACE_QUERY=0`，就只存它的长度和哈希。目前有一个例外：如果你自己加了可选的 `add absence` 或 `add coverage` 规则，轨迹里这两条规则的记录会把搜索词和各种拼法原样存下，`TGLW_TRACE_QUERY=0` 也管不到。
- **大小。** 所有轨迹合计默认不超过 100 MB（`TGLW_TRACE_MAX_MB`），超了先删最旧的。
- **删除。** 随时可以删掉 `traces` 目录；或者设 `TGLW_TRACE=0`，不再记录。
- **不影响回答。** 记录不会改变工具返回的内容：在我们测过的文档上，把录下的 1,869 次工具返回在记录关、开、以及打开 `trace` 工具三种情况下回放，全部逐字节相同。
