## Models downloaded at run time

vestigium does not ship any of these files. They are fetched on the user's machine, the first time they are
needed, by the libraries named below. Licenses as found with docling 2.117.0 and rapidocr 3.10.0; "not found"
means we found no license statement for the file.

| File | Fetched by | When | License | Where the license is stated |

| Layout model `docling-project/docling-layout-heron` | Docling | first `vestigium ingest` conversion | Apache-2.0 | the model card (README.md) downloaded with the weights |
| Table model TableFormer (`docling-project/docling-models`, `model_artifacts/tableformer`) | Docling | first `vestigium ingest` conversion | CDLA-Permissive-2.0 | the model card (README.md) downloaded with the weights |
| RapidOCR ONNX models `PP-OCRv6_det_small`, `PP-OCRv6_rec_small`, `ch_ppocr_mobile_v2.0_cls_mobile` | Docling (RapidOCR) | first conversion with `--ocr rapidocr` (the default) | Apache-2.0 (weights from PaddleOCR) | rapidocr's `MODEL_LICENSES.md`, section 6 |
| RapidOCR PP-OCRv4 torch weights (`.pth`) and paddle dictionary files | Docling (RapidOCR download) | same | not found | not listed in rapidocr's `MODEL_LICENSES.md` |
